# 中期验收方法与覆盖限制

本页说明 `tests/midgame-interactions.mjs` 和 `tests/research-interactions.mjs` 的可重复检查方法，不是整阶段通过声明。脚本由 `tests/runtime.mjs` 调用，主题与固定上游 reference 使用独立浏览器上下文。购买、解锁和重置通过 Playwright 点击原组件执行，双方使用相同阶段状态。

## 运行

完整回归使用 `pnpm test:runtime`；产物指纹过期时先运行 `pnpm test`。Windows 需要 Google Chrome。

单独定位中期用例：

```powershell
$env:TEST_OUTPUT_DIR = Join-Path $PWD 'test-results/midgame'
$env:TEST_FILTER = 'Midgame UI'
pnpm test:runtime
Remove-Item Env:TEST_FILTER
```

Deadline-Carl 下 `TEST_OUTPUT_DIR` 必须指向监督器指定的 scratch 目录。`runtime-report.json` 中 `filter` 为非空值时只是筛选运行，不能替代最终完整检查。断言失败会使命令非零退出。

## 操作覆盖

| 系统 | 自动化操作与边界 |
| --- | --- |
| 转生魂契 | 前置未购买、资金不足；16 格基础魂契按原顺序、精确费用购买，核对原 ID 和效果 |
| 打破魂界 | 转生执役间隔 101ms 时拒绝；100ms 时打开原确认框，确认前不改变状态，确认后对照自动化奖励 |
| 通灵议会 | 八阶原游魂解锁阈值前后、真实解锁按钮；费用不足不购买、精确费用购买十个单位；议会入口可点击 |
| 疫种 | `1e140` 魂印前后解锁；概率、间隔、墓域上限三类升级的不足与精确费用 |
| 执役 | 第一阶慢速执役的原累计游魂门槛、试炼完成夹具后的间隔升级费用、购买模式及全局启用按钮 |
| 墓园祭坛 | 前四阶轮回印费用；后四阶按前置研究与精确典籍数量解锁，再验证轮回印购买费用 |
| 轮回重置 | 轮回数 0、1、2、3、19、20 的阶段夹具，真实轮回按钮与确认框，逐次对照魂契、议会、疫种、执役、祭坛等状态 |

`midgame-operations.json` 逐步保存夹具代码、操作标签、主题实际状态与原版期望状态。包含资源、维度、升级集合、自动化、疫种、研究、永夜、试炼及三类维度的计算倍率。截图用于检查界面，不替代操作断言。

## 夹具与未覆盖内容

测试明确提供资源和阶段进度，不声称从新存档自然积累到中期。后四阶祭坛夹具直接授予永夜研究；执役升级夹具直接完成第一试炼；轮回保留测试直接初始化已购买系统。正常永夜开启、试炼完成和跨阶段积累仍须单独验证。

创世基础对照使用 120 秒阶段时间，避免原作成就 154 的 10% 随机翻倍奖励干扰确定性重置比较；没有修改成就、奖励、随机函数或原作种子。该测试不覆盖成就 154 的随机奖励统计。

## 试炼、研究与永夜操作链

`TEST_FILTER='Research UI'` 单独运行研究模块；完整回归不设置筛选变量。`research-operations.json` 保存每组夹具、逐步操作标签及双方状态。断言除原版同状态比较外，还明确检查购入、完成、当前试炼编号、退款和永夜开启状态，防止双方都未执行操作却错误通过。

| 系统 | 操作链 |
| --- | --- |
| 冥典树 | 创世前全部普通研究逐项检查无前置、费用不足、精确费用；逐项检查 `requiresST` 互斥伙伴在无空间典籍时被拒绝；TS181 分别缺 EC1/2/3 完成记录时拒绝；另有 11→21→31→41→51→61→71 连续购买、71 排斥 72/73、点击重洗选项后真实轮回并核对全额退款 |
| 亡灵试炼 | C2–C12 按原门槛初始化轮回前转生次数，逐个点击进入、购买第一阶、运行原模拟 50ms、退出；再次进入后比较目标以下和目标处的真实转生完成。C1 首次转生由初期测试覆盖 |
| 破界试炼 | IC1–IC8 用各自原始游魂解锁门槛，执行相同进入、生产、退出及完成链；不直接设置完成位 |
| 轮回试炼 | EC1–EC12 的五档目标分别用 0–4 次完成历史夹具检查；不足/精确典籍、二级资源不足/精确门槛（EC1–10）、禁用研究路径（EC11/12）；真实购买研究、进入，目标以下无完成，精确目标真实轮回并核对研究退款、完成数、奖励与重置 |
| 失败规则 | EC4 各档次数上限处仍允许，真实转生一次触发超限退出；EC12 各档游戏时间限制前仍允许，原模拟推进后触发失败；核对弹窗、退出重置和完成数不增加，再真实关闭弹窗 |
| 轮回里程碑 | 全部 27 项分别从阈值前一次轮回的阶段夹具出发，真实轮回跨越阈值；逐项核对原状态、页面达成样式数量及重置保留。离线奖励实际结算仍需存档/离线专项测试 |
| 永夜 | 前置末层研究夹具，EC12 第四次完成不足；总典籍不足；满足原门槛后真实购买永夜研究；进入确认、原模拟产出、退出确认及保留状态 |

测试停止自动时钟，设置原作允许的资源/历史字段跳过漫长积累，并使用原始 `gameLoop` 推进明确时长。重置后读取计算倍率前使原作 Lazy 缓存失效，以免停止时钟后读到前一帧缓存；没有修改任何模拟公式。逐项研究检查的父研究、EC 完成测试的前置研究和 0–4 次历史、永夜所需 EC11/12 完成历史均为明确夹具，不能代表那些历史自然获得。五档 EC 用例相互隔离，不声称是从第一次连续积累到第五次的自然流程，也不覆盖特殊领域中的规则。
