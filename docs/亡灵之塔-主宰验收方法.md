# 主宰操作对照：当前覆盖与限制

本文件记录部分开发检查，不是七主宰或终局验收完成声明。原内核固定提交、全部公式和源 ID 保持不变。

运行 `pnpm test:runtime` 会包含 `tests/celestial-interactions.mjs`。单独复现时设置 `TEST_FILTER=Celestial UI`，并把 `TEST_OUTPUT_DIR` 指向本轮 scratch 目录；取消筛选后才能运行全量回归。生产样式变更后先运行 `pnpm build`，不能复用过期指纹。reference 使用独立浏览器上下文。

操作轨迹写入 `celestial-operations.json`，包含每个操作后的主题/原版快照。重置检查比较资源、筑塔墓域、魂契、祭坛升级、研究、冥器、种子和三个主宰状态；不会仅比较运行标志。

Teresa 的原固定宽度布局在经营栏中发生左侧裁切，主题 CSS 改为换行排列并给容器侧面的阈值说明保留空间。测试遍历 320/375/414/768/1024/1440 宽度，对领域、灌注、五个商店按钮执行边界与中心命中检查，并留存截图。布局检查不是自然灌注玩法验证。

## 夹具来源与未覆盖范围

以上测试从原 `Player.defaultStart` 重置，设置 5 次创世、成就 147、固定时钟与种子，停用自动模拟以便精确比较。Teresa 使用人工 `pouredAmount` 加原阈值检查解锁；Effarig 的碎片按原价格注入；Laitela 直接设置虚冥升级 15 的历史位。它们均为阶段夹具，未通过正常游玩积累这些资源和历史条件。

尚未验证真实灌注时间/所有阈值、商店满级和音乐冥器、三领域通关奖励与重试、Effarig 三阶段解锁链、其他灾厄化身阶位/升阶/湮灭、死星所有里程碑/批量与自动化。Enslaved、V、Ra、追忆、炼金、虚冥购买仍不在本模块实质操作覆盖内。Pelle 封界、五裂隙及织机的新增部分检查见《亡灵之塔-终焉验收方法.md》；完整封印与结局链仍未覆盖。
