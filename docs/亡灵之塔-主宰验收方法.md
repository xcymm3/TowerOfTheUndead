# 七位主宰验收方法

本文件记录直接开发第 3 步的可复现验收范围。原作内核固定在 `5409e320cecef96a917cca1dfb68f1f183e499ca`；820 个上游文件、767 条映射、公式、费用、随机种子、重置和保留规则均未改动。

运行 `TEST_FILTER="Celestial UI|Celestial completion" pnpm test:runtime` 可复现主宰回归。主题版与未换肤 reference 位于两个独立浏览器上下文；每项操作后比较玩家状态、资源、领域标志、奖励和相关派生值。正式产物需先执行 `pnpm build`，再执行 `pnpm test:production`。

## 操作覆盖

| 主宰 | 操作路径 | 核对结果 |
| --- | --- | --- |
| 墓园摄政者 | 原商店边界、进入/退出；以原创世结算事件完成领域 | 最佳记录与领域奖励倍率保留，主题版和 reference 一致 |
| 遗物典藏官 | 原商店与进入/退出；依次触发转生、轮回、创世结算 | 三层封印按原顺序解开，阶段、奖励与退出状态一致 |
| 缚时幽魂 | 两种时间封存开关、两项等价购买边界、提示进度、领域完成、折叠墓室购买 | 互斥封存、完成奖励、费用与保留状态一致 |
| 恐惧骑士长 | 成就 151 与六项原条件解锁、领域进入、六项功业、奖励、重试和提前退出 | 分级完成数、誓约页、奖励解锁、重试/退出状态一致 |
| 不朽巫妖 | 四位先祖依次解锁、两类记忆升级、追忆生产与凝视、炼金反应、特殊冥器 | 原英文名字仍作为存档逻辑键；显示翻译不再改写追忆字段；反应和冥器消耗一致 |
| 灾厄君主 | 四阶化身三类升级、虚渊晋升、湮灭、八阶领域奖励、死星凝聚与上限控制 | 四阶状态、奖励、批量阈值、30 项里程碑及 4 个自动化开关一致 |
| 死亡化身 | 未封界页面、自然前置边界与解锁条件显示 | 本步只确认第七主宰页面可达且未伪造封界；封印、裂隙、织机和结局归第 4 步 |

`tests/celestial-interactions.mjs` 保留此前 Teresa、Effarig、Laitela 的价格边界和进入/退出检查；`tests/celestial-completion.mjs` 增加上述完成链与奖励检查。操作轨迹写入 `celestial-operations.json` 和 `celestial-completion-operations.json`。

## 阶段夹具边界

长线资源使用显式阶段夹具：创世次数、成就、历史最高值、原升级位与恰好价格的资源会直接注入；购买、开关、领域确认、重置、阶段完成和奖励仍调用原控件或原事件路径。V 的功业逐项调用原条件检查，Ra 的先祖按等级门槛依次解锁，Laitela 的 30 项死星里程碑逐项检查阈值前后。此证据不表示从新档自然等待到七主宰的时间成本已被实跑。

## 界面与文案

七页分别在 320、375、414、768、1024、1440 宽度检查根容器与可见控件边界并留存截图。主宰页改为可换行布局；V 六边形在窄屏改为单列卡片；Ra 宠物、追忆和炼金容器自适应；Laitela 化身、死星、湮灭和里程碑改为可堆叠布局并修复低对比；Pelle 解锁条件不再按 50rem 固定宽度溢出。关键主宰术语、操作按钮与规则说明已同步本地化，完整 767 条映射及数据库外全文审计仍归第 5 步。

## 未覆盖范围

本步不触发 Pelle 封界，不验证五条裂隙、终焉升级、装备槽恢复、万墓织机、字幕或真实结局；这些属于第 4 步。历史/损坏存档、全部备份类型、长离线、持续运行、全量集中回归属于第 6 步，GitHub Pages 发布属于第 7 步。
