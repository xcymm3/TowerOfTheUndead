# 终焉操作对照：当前覆盖与限制

本文件记录 `tests/endgame-interactions.mjs` 的开发检查，不是终局验收完成声明。原模拟代码、价格、资源上限与阶段顺序未改动。

`pnpm test:runtime` 包含本模块。定向复现时设置 `TEST_FILTER=Endgame UI`，并将 `TEST_OUTPUT_DIR` 指向本轮 scratch 目录。取消筛选后运行全量回归。主题与 reference 使用独立浏览器上下文；操作轨迹写入 `endgame-operations.json`，包含夹具说明和逐操作两侧快照。

## 实际操作和比较内容

| 路径 | 实际动作 | 检查内容 |
| --- | --- | --- |
| 封界入口 | 未满足条件时入口隐藏；全部所需成就完成，但一项炼金资源低于自身上限时仍隐藏；达到上限后点击入口 | 同状态原版比较，炼金上限按原提炼历史计算 |
| 首次封界 | 取消确认框，再次进入并确认 | 取消保留状态；确认清零低层资源、筑塔墓域及炼金，比较冥器、研究、主宰状态、禁用机制 |
| 执役恢复 | 第一项单次封界升级不足价格和恰好价格时点击 | 不足失败；恰好支出后恢复前四阶执役，其他封界限制保留 |
| 五裂隙 | 点击前两条后点击第三条；再分别启用每条裂隙 | 第三条被拒绝，原版最多两条同时吸取 |
| 15 个裂隙里程碑 | 将填充值置于阈值前，真实点击开启吸取，再运行原版一秒裂隙计时 | 每个里程碑由未解锁跨越到解锁，比较资源支出、填充比例、效果和全部里程碑；满额后原版计时自动关闭，未满额可点击停止 |
| 织机解锁及五项升级 | 递归裂隙达成条件后真实点击解锁；每项升级分别使用一半和恰好费用点击 | 购买失败/成功次数、费用支出、生成倍率及主宰状态对照 |
| 织机五阶段 | 每阶段资源在上限前点击无效，达到上限后点击牺牲；运行原版 16 秒再 18 秒计时 | 不修改阶段和牺牲标志；比较部分吸取、里程碑失效、阶段推进，顺序为 vacuum → paradox → decay → chaos → recursion |
| 织机恢复 | 五阶段结束后运行原版 70 秒计时 | 无上限状态、全部裂隙恢复至 200%，两侧状态一致；此时明确断言尚未触发结局 |

快照包括封界完整状态及升级 Set 的显式数组、主要资源、炼金、研究、冥器、筑塔墓域、禁用规则、五裂隙效果和织机速率/上限。定向操作结果不能代替全部终焉升级和规则审计。

## 夹具与限制

所有测试从原 `Player.defaultStart` 开始，使用固定时钟/随机种子并暂停自动模拟。注入 100 次创世、成就 147、虚冥升级 25，以便定位页面。首次封界另注入此前成就、基础炼金提炼历史和资源；不宣称这些历史经自然流程获得。封界会按原行为跳转初期页面，升级恢复检查再定位主宰页面。

裂隙用例直接设置封界和五次封印历史，绕过封印达成链；每个里程碑检查前重置相关填充值并注入吸取资源，不是连续自然填满五裂隙。混沌吸取衰变的百分比，其他裂隙吸取各自原货币。调用原 `Pelle.gameLoop` / `GalaxyGenerator.loop` 模拟明确时长，不是等待真实墙钟时间，也不验证完整生产与离线结算。

织机用例直接提供满额裂隙及破界历史，在每阶段注入所需生成资源。五次牺牲本身均由真实按钮发起，阶段推进来自原计时逻辑；没有直接写入阶段、牺牲标志或结局标志。还未覆盖生成资源的完整积累、全部升级级别、末期反物质生产触发结局、字幕和新游戏按钮路径。

本轮截图仍可见中英混排、裂隙动态乱码效果及经营栏宽内容裁切，未完成逐文本主题审计、六宽度终局响应式验收和全结局文案审计。封界其余升级/保留规则、完整封印触发链及真实结局触发仍为未验收，不因本模块通过而改变 AC8/AC9/AC10/AC12 的状态。
