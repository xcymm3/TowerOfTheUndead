# 终焉操作对照

`tests/endgame-interactions.mjs` 覆盖终焉封界至新游戏的完整闭环。定向复现使用 `TEST_FILTER='Endgame UI'`；操作轨迹写入 `endgame-operations.json`，主题版每一步均与独立原版上下文比较。

## 实际操作与结果

| 路径 | 操作 | 完成检查 |
| --- | --- | --- |
| 封界入口 | 验证成就与炼金边界，取消一次确认后再次确认 | 取消不改变状态；确认执行原封界重置、清空炼金并启用禁用规则 |
| 终焉升级 | 5 项有限重复升级分别验证零资源、恰好费用和上限；23 项一次性升级依次点击 | 费用、购买次数、封顶及恢复能力与原版一致；焚界后显式保留项成立 |
| 五道封印 | 实际转生、购买墓域强化、实际轮回、购买第 115 页冥典、进入永夜 | 五个 `progressBits` 只由原事件写入，逐次比较规则、奖励和裂隙解锁 |
| 五条裂隙 | 点击启停并尝试第三条同时填充；在每个里程碑前运行原填充循环 | 同时上限为 2；15 个里程碑、资源消耗、效果与满额停机一致 |
| 万墓织机 | 界面解锁，五项升级验证不足/足额；达到各阶段上限后点击献祭 | 按空冢、逆命、腐朽、乱葬、归骨顺序推进，不直接写阶段或献祭标志 |
| 冥器槽 | 空冢里程碑后装备终焉冥器；首次献祭清除里程碑；五阶段后回填 | 槽位 1 → 0 → 1，冥器被强制卸下并可重新装备 |
| 裂隙恢复 | 五次献祭结束后运行原织机循环 | 织机解除上限，五裂隙均恢复到 200% |
| 真实结局 | 由亡灵军团实际生产跨过累计游魂阈值，再运行原结局循环 | `player.isGameEnd` 由 `GameEnd` 设置；淡出、字幕、新游戏入口出现，可关闭和重开字幕 |
| 新游戏 | 选择确定的冥器外观后点击新游戏入口 | 原保留式重置执行，通关次数增加，封界和结局标志退出 |

## 夹具边界

测试从 `Player.defaultStart` 开始，使用固定时钟和独立上下文。为缩短长线等待，可注入下一事件所需的资源、历史次数、裂隙填充值和织机生成量；不会直接设置封印历史、织机阶段、献祭状态、冥器槽恢复标志或结局标志。裂隙里程碑逐项从阈值前推进，不声称连续自然等待完整资源积累。终幕音乐在测试中以成功的媒体播放桩代替，字幕状态机和界面仍使用原实现。

## 界面

终焉封印、裂隙、余烬升级、万墓织机和新游戏关键操作已本地化。五裂隙保留原数组和状态逻辑，但中文主题不再套用只适合拉丁字符的乱码扰动。终局容器、升级卡、裂隙行、织机和新游戏面板支持换行；新游戏面板增加终幕背景对比，并在字幕阶段隐藏会遮挡窄屏入口的旧通知。320、375、414、768、1024、1440 六档均检查水平边界并留存截图。
