# 映射审计方法与当前限制

运行 `tests/runtime.mjs` 中的 `767 mappings bind to their original config objects` 用例，会在 `TEST_OUTPUT_DIR` 输出 `mapping-audit.json`。可设置 `TEST_FILTER=767 mappings` 单独运行；不设置筛选时也会随完整回归输出。

报告逐条保留 767 个唯一 mappingKey、group/key、源 ID、主题名、固定源文件与行号、原始 fields 表达式，以及浏览器中实际配置对象的 ID、主题名和绑定检查结果。没有显式 id 的原配置以 null 记录，不将其误判为错误；有些映射使用位置或父键作为源标识。

`bindingStatus=PASS` 仅表示 registry 对象与 configurations 对象相同、主题名符合索引。它不能证明生成绑定选中了正确的源对象，也不能证明页面显示、表达式语义或正常解锁路径正确。源文件未改由独立的 `scripts/verify-source.mjs` 检查。

当前逐条 `displayStatus` 和 `semanticStatus` 均为 UNKNOWN。后续审计须为每项补充真实显示位置/截图、源对象路径核对、原表达式语义复核及必要的动态状态操作。报告中的数据库外分类只是待盘点目录，尚不是完整文本清单。已有阶段截图中的中英混排、动态说明及布局缺口仍待处理，不能以 767 个绑定通过宣布 AC10 完成。

本轮只扩展测试报告，不改变游戏、翻译或数值。定向运行通过不替代新测试版本的完整回归；此前完整 74 项结果属于修改前版本。
