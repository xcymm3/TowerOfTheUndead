# Headless 真实浏览器通关试玩规格

## 方法边界

- 使用 Chromium headless，不打开可见窗口，不接管或锁定系统鼠标。
- 从空白存档开始，所有购买、升级、挑战、重置、自动化配置和结局操作只点击浏览器中实际可见、可用的控件。
- 允许只读采集引擎阶段、资源和计时数据用于策略判断；禁止写入玩家字段、注入资源、导入阶段存档或调用测试夹具。
- 自然完整流程需要多天，因此等待使用真实“保存 → 离线 → 重新载入”路径，并通过浏览器时钟偏移压缩墙钟时间；离线收益仍由正式游戏逻辑计算。分别报告实际墙钟时间和模拟游戏历时。

## 验收目标

1. 连续存档从新游戏推进至真实结局，且不是直接设置结局标志。
2. 保存全部阶段时间、点击策略、错误、失败请求和代表截图。
3. 检查 1440、1024、768、414、375、320 宽度下的主要阶段展示与可操作性。
4. 记录玩法阻塞、显示异常、控制失效、报错和网络资源问题；区分产品缺陷与自动试玩策略失误。
5. 给出可复用策略、实际墙钟用时、模拟游戏历时与最终结论。
